Etiqueta corta en mayúsculas para categorías y estados. `brand` marca el producto insignia o una novedad; `neutral` clasifica (vertical, módulo); `success`, `warning`, `danger` e `info` son estados y llevan siempre icono o una palabra que los nombre.

- Máximo dos palabras.
- `pill` para estados de licencia o de documento (Activa, Por vencer, Rechazada); esquinas `radius-sm` para categorías.
- No la uses como botón ni como enlace.

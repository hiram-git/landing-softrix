Campo de texto o área de texto con etiqueta, ayuda y mensaje de error enlazados por `aria-describedby`. Es el campo del formulario de solicitud de demo y de contacto de distribuidores.

- Etiqueta siempre visible; el placeholder es un ejemplo, no la etiqueta.
- Marca los opcionales con `optional` en vez de poner asteriscos en los obligatorios.
- `error` sustituye a `hint`, nunca conviven; el mensaje dice qué corregir («Escribe un correo con @»).
- Borde `border-strong` en reposo, `ink` al pasar el cursor, `danger` con error; el foco es el anillo global `focus`.
- Agrupa campos con `space-4` de separación vertical.
